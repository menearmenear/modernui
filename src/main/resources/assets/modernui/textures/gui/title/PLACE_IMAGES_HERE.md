Drop these two files in this folder to replace the vanilla logo:

- `minecraft_glass.png`  — 256 x 64, wordmark in the top 44px
- `edition_glass.png`    — 128 x 16, "JAVA EDITION" in the top 14px

Both need a fully transparent background. See `ASSET_PROMPTS.md` at the project
root for copy-paste prompts. Without these files the vanilla textures are used.
